# 基础配置与 Agent 管理接口黑盒测试方案

## 测试范围

- 范围内：Agent、HTTP Connector、飞书机器人 CRUD、两种入口模式、授权 options/resolve、长连接事件移交、启停、连接测试、权限、数据隔离、凭据脱敏、确定性 Mock Agent。
- 范围外：正式运行、Redis 调度、流程发布、命令路由、飞书回复和运行中心。
- 假设：服务基址为 `/jeecg-boot`，接口沿用 JEECG `Result<T>`；真实飞书验收需要有效凭据和外网。

## 兼容性验证

| 契约区域 | 既有行为 | 验证方式 | 风险 |
| --- | --- | --- | --- |
| 响应封装 | JEECG `Result<T>` 和 `IPage<T>` | 校验 `success/code/message/result` 与分页字段 | 前端响应转换失败 |
| 鉴权权限 | Shiro 菜单和按钮权限 | 管理员、只读角色、无权限角色分别调用 | 误放行写接口 |
| 租户与部门 | `tenant_id`、`sys_org_code` 数据规则 | 使用不同租户和部门 Token 访问同一 ID | IDOR 或跨租户泄漏 |
| 逻辑删除 | 删除后默认查询不可见 | 删除后按 ID、列表及重复编码创建 | 稳定代码被意外复用 |

## 测试数据计划

| 数据用途 | 表/集合 | 必填字段 | 构造方式 | 清理方式 |
| --- | --- | --- | --- | --- |
| 无鉴权连接器 | `ai_connector` | code、URL、path、超时 | 指向 Mock Agent | 先禁用后删除 |
| Bearer/API Key | `ai_connector` | authType、secret | 本地 HTTP 模拟服务验证请求头 | 先禁用后删除 |
| 飞书机器人 | `ai_feishu_bot` | botKey、appId、appSecret、entryMode、commandEnabled | 模拟飞书服务；真实凭据仅人工验收 | 解绑后删除 |
| Agent | `ai_agent` | code、name、connectorId | 分别构造无机器人、正常绑定、冲突绑定 | 先禁用后删除 |
| 越权数据 | 三张表 | 不同 tenant/org | 两组独立账号创建 | 各账号自行清理 |

## 性能测试评估与建议

| 接口/链路 | 是否建议 | 原因 | 建议场景 | 指标建议 | 数据量/并发建议 |
| --- | --- | --- | --- | --- | --- |
| 三类分页列表 | 是，轻量基准 | 管理端常用且包含筛选 | 1 万条数据分页与排序 | P95 < 500ms、错误率 0 | 1 万条、并发 10 |
| Connector/飞书测试 | 是，并发稳定性 | 依赖外部 HTTP 和超时 | 成功、慢响应、超时混合 | 无连接/线程泄漏，错误率符合模拟结果 | 并发 20 |
| Agent 启用 | 是，并发一致性 | 存在机器人行锁竞争 | 同一机器人并发绑定 | 仅一个成功，无死锁 | 并发 20 |
| 飞书事件移交 | 是，队列稳定性 | SDK 回调不可被业务处理阻塞 | 慢处理、异常、队列饱和 | 回调快速返回，线程和队列有界 | 并发 20、队列 200 |

| ID | Provider/场景 | 关键请求断言 | 响应断言 | 预期结果 |

| M-02 | DeepSeek TEXT | 独立默认地址/Path，复用 OpenAI Adapter | OpenAI-compatible 响应 | 不复制业务逻辑 |
| M-03 | Anthropic RESULT_1_1 | system、messages、max_tokens、x-api-key、anthropic-version | content text 数组 | 严格 Result 1.1 |

| M-05 | Ollama TEXT/RESULT_1_1 | messages、options、stream=false、format=json | message.content | TEXT 或严格 Result 1.1 |
| M-06 | Custom 回归 | LEGACY 旧信封/Pointer；1.1 旧请求信封 | 旧映射或严格结果 | 现有 Connector 无需修改 |
