## 主要风险

- trigger alias 的最终并发保证依赖 MySQL 唯一键和事务回滚，静态及单元验证不能替代真实数据库证据。
- Agent 快照会冻结 systemPrompt 和非密钥 Connector 配置；发布服务已过滤 Authorization、X-API-Key 和 secret 类请求头，后续新增敏感头命名时需同步过滤策略。
- 机器人或 Agent 禁用会阻止新运行，但历史版本仍保留；运行中心必须使用展示脱敏 DTO，不得直接返回内部 `definition_json`。
- 当前 Vue 类型检查工具版本失配，生产构建通过不等同于完整类型检查通过。
